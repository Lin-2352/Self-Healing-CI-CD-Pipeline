LAUNCHER STEPS (double-click the .bat files in this folder, in this order)

PATH A - n8n on this PC (the normal demo)
  1. 1_start_model_on_kaggle.bat      start the Qwen model on Kaggle (about 4 min). Wait for the URL line.
     show_model_info.bat              optional: prints the model address and whether it answers.
  2. 2_load_workflow_into_n8n.bat     load the workflow and credentials into the local n8n (about 1 min).
  3. 3_start_n8n_live.bat             start n8n with the public webhook (about 1 min). Opens http://localhost:5678
  4. Break the app, push, and watch GitHub Actions, the n8n Executions tab and the Pull requests tab.

PATH B - the local n8n does not work: use the web n8n
  1. 1_start_model_on_kaggle.bat      same as above.
  2. cloud_n8n_connect_model.bat      tells the web n8n where the model is, then opens
                                      https://self-heal.app.n8n.cloud/workflow/RqeD38ZnSeV64SHd
                                      (the workflow is already loaded and published there)
  3. Skip steps 2 and 3 of path A. Do NOT run 3_start_n8n_live.bat: it points the GitHub secret at your PC.
  4. Break the app, push, and watch the Executions tab of the WEB n8n.

OTHER
  start_n8n_local_only.bat            open the local n8n workspace only (no model, no tunnel, nothing on GitHub).
  4_start_backend.bat                 start the second healer (ci-heal-backend) on port 8000. Needs the model.

WHEN DONE (launcher\end)
  stop_everything.bat                 stops the backend and n8n; then stop the Kaggle session on kaggle.com.

If the local n8n says "NOT ready after 240s (last status 404)": run 2_load_workflow_into_n8n.bat again (it carries
the fix), or switch to path B.
