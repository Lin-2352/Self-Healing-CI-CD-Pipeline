Known limits

  • Retries can anchor on a wrong first fix. On callback_arity the first fix kept the wrong callback signature, and the retries chased the new error text instead of revisiting it. The next step is a neutral retry prompt, tested offline first.
  • A retry that produces no commit is silent. Fixed (see the top of the page): the model call is streamed, and any heal that ends without a fix posts a comment explaining why.
  • A failure after the fix is pushed is still not commented. If Create Branch, Push Fix File or Open Pull Request errors, the n8n run fails without a comment. These GitHub calls have not failed in any live round.
  • A first fix that does not parse opens no PR, so it never gets a retry.
  • Small test surface. All 11 bugs live in one ~50-line Node/Express smoke test. This measures the pipeline's bug types, not general coding ability.
  • Kaggle queueing. The eval kernel waited about 2.5 hours for a free T4×2 before it started.
